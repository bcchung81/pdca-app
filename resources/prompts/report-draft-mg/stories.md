## 구성: 평가내용 → 대주제 → 절
- 보고서 한 건은 지표 하나입니다. 평가내용 띠 아래 대주제 번호 상자(1·2·3)가 오고, 대주제 안에 절(가.·나.·다.)이 옵니다. 절은 한 쪽 안에 들어가고 쪽당 2~3개입니다.
- 절의 골격은 **왼쪽 어두운 라벨 칸 + 오른쪽 내용 칸의 라벨 사다리**이고, 맨 아래는 어두운 라벨 「추진성과」 행(불릿 + 증감 칩 + 막대)이나 구분표의 「추진실적」 열이 닫고, 대주제의 마지막 절이 그 대주제 공용 추진성과로 닫기도 합니다(2025 절의 약 절반은 추진성과 행 없이 끝남 — 14개 지표 육안). 지표마다 관례가 달라 요청에 적힌 이 지표의 「닫기 관례」를 따릅니다(안전한 일터 조성·AI 활용 혁신은 2025 절이 모두 「추진성과」 행으로 닫힘). 같은 짜임은 거의 없어(블록 종류·순서·라벨이 절마다 다름) 틀은 출발점이고 블록은 구성안에서 고칩니다.
- 평가내용의 **첫 대주제는 「전략수립」** 체계도형인 곳이 많습니다(환경분석 → 시사점 → 전략목표 → 추진전략 → 실행과제 → 성과지표). 카드에는 이 재료가 없으므로 공통 지식(관리계획·편람·평가위원 의견·전년 절)에서 뽑고, 근거에 없는 칸은 지어내지 않고 「자료 필요」로 남깁니다.
- 절 제목 줄 끝에 마커(지적개선·BP·신규·AI)와 분류 꼬리표가 붙습니다.

## 이야기 틀(story)
내용 성격을 보고 절마다 주 틀 하나를 고릅니다. 다른 틀의 한 행·한 블록이 꼭 필요하면 보조 틀 하나를 더합니다(주 틀 + 보조 틀 — 「섞음」은 없음, 보조 틀의 블록은 그 틀이 드러나는 한 자리에만). 블록 순서는 예시입니다. 2025 예시는 「지표 평가내용-대주제(-절)」(2025 연번)이고, 14개 지표 223단위 육안에서 주 틀은 ② 30%·⑦ 25%·③ 15%·① 12%·④ 6%·⑤ 5%·⑧ 4%·⑥ 3%, 섞음 35%였습니다(①~⑧로 셌을 때 — 그때 섞음·⑤·⑦로 셌던 단위 중 □ 소과제 묶음 23·생애주기 5·준수 점검 2가 ⑨~⑪이고, 섞음은 「주 + 보조」로 판정해 적은 것이라 지금은 주 틀 + 보조 틀로 씁니다).
① 전략수립형 — 평가내용의 첫 대주제: cards(환경분석 외부·내부 2칸) → banner(시사점) → quotes(기관장 의지) → strategy(전략체계도 — 목표 띠 → 전략목표 열 → 실행과제·성과지표, 층 이름은 지표마다 다름) → chart(핵심성과 막대) (2025 예: 윤리경영 1-1 · 창업 1-1 · 상생·협력 1-1 · 재무예산 1-1 · 노사관계 1-1 · 안전한 일터 1-1)
② 배경·내용·성과형 — 기본형: bullets(추진배경) → cards(추진내용 박스 열) → steps(추진내용 흐름) → stats(추진성과) → chart (2025 예: 상생·협력 1-2 · 윤리경영 1-2 · 안전·재난 1-3 · 안전한 일터 1-4)
③ 문제·해결형 — 현장·제도의 문제 먼저(이용자·현장의 불편, 제도·환경의 한계 — '25 지적은 문제의 근거 중 하나일 수 있으나 지적으로 열지 않음): cards:vs(문제인식) → steps(혁신포인트) → compare:table(추진내용) → stats(추진성과) (2025 예: 노사관계 1-2 · 전략기획 2-3)
④ 기존·개선형 — As-Is → To-Be(기존 = 현장·제도에서 드러난 한계 — '25 지적 문구가 아님): bullets(추진배경) → compare:panels(기존→개선) → compare:table(추진내용) → stats(추진성과) (2025 예: 노사관계 1-3-가 · 조직·인적자원 1-2 · 재무예산 1-2-가)
⑤ PDCA 체계형 — 계획 → 운영 → 점검 → 환류: banner(개선방향) → pdca(계획수립 → 평가운영 → 성과점검 → 보상·환류 4칸 + 환류 띠 — 관리 단계 순환이어도 됨, 대상자의 생애 단계면 ⑩) → table(추진내용) → stats(추진성과) (2025 예: 조직·인적자원 2-1 · 안전·재난 2-3-다 · 상생·협력 1-4-다)
⑥ 단계·연도 로드맵형 — 해마다 쌓은 단계: timeline:chevron(추진경과 '23·'24·'25) → compare:table(추진실적) → stats(추진성과) (2025 예: 노사관계 1-3-나 · 안전·재난 2-2-라 · 창업 2-3-나 · 안전한 일터 1-5-가)
⑦ 구분표 중심형 — 「구분 | 주요활동 | 추진실적」 표가 본문: bullets(추진배경) → table(구분·주요활동·추진실적) → stats(추진성과) (2025 예: 노사관계 2-1 · 재무예산 3-2 · 상생·협력 1-3-다)
⑧ 계량 모니터링형 — 수치 격자·증감 막대·월별 매트릭스: table(현황분석) → chart(증감) → table(관리방안) → stats(추진성과) (2025 예: 재무예산 1-2 · 재무예산 1-3)
⑨ 소과제 묶음형 — 절 하나에 독립 소과제 2~4개: bullets(추진배경, 절 공통 한두 줄) → subhead(① 소과제) → cards(그 소과제의 추진내용 박스 열) → subhead(② 소과제) → table(구분·추진내용·추진실적) → stats(추진성과 — 소과제마다 결과 줄). 소과제마다 블록 하나둘로 짧게, 같은 소과제 안에서만 내용과 실적을 잇습니다 (2025 예: 일자리 1-2-가 · 일자리 2-1-가 · 친환경 1-3-가 · 상생·협력 2-4-나)
⑩ 생애주기형 — 대상자의 생애 단계마다 지원을 잇는 과제(임신·출산 → 육아 → 복직, 채용 → 교육 → 승진 → 퇴직): bullets(추진배경) → steps(생애 단계 흐름 — 단계마다 지원 하나) → table(구분 칸이 생애 단계·추진내용·추진실적) → stats(추진성과). 단계는 사업 단계가 아니라 사람의 생애 단계입니다 (2025 예: 일자리 4-2 · 보수·복리후생 2-3-나 · 조직·인적자원 4-2 · 조직·인적자원 5-2 · 노사관계 3-2)
⑪ 준수 점검형 — 정부 지침·권고를 지켰는지 보이는 과제: bullets(정부지침·권고 근거) → table(항목·정부지침·기관 이행·준수 여부) → steps(미준수 항목 → 노사협의 → 차년 계획) → stats(추진성과). 준수 여부와 미준수 항목은 근거에 있는 것만 씁니다 (2025 예: 보수·복리후생 1-3 · 조직·인적자원 4-1)
⑫ AX 전환형 — AI·자동화로 업무 절차를 바꾼 과제: cards:arrow(전환 배경 — 기존 절차의 한계 ▶ 전환 동인 ▶ 새 방식 3칸) → compare:panels(기존→AI 전환 — 기존 절차 ↔ AI 적용 절차, 단계·소요 시간) → table(역할 분담 — 머리 줄 구분 | AI | 사람, AI가 맡는 반복·탐지, 사람이 맡는 판단·결정) → steps(확산) → stats(추진성과 — 절차 단축·성과 수치). 기존·새 절차의 단계(또는 소요 시간 전후)와 역할 분담이 근거에 있어야 하고, 없는 칸은 지어내지 않고 「자료 필요」 재료·【확인: …】로 남깁니다. 「AI」를 주제어로만 쓰지 않고 바뀐 절차와 성과로 씁니다 (2025 예: 없음 — 타기관 AX 사례에서 뽑음)
