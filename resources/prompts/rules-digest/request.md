# 고쳐 만들기
앞 판 규칙 문서를 다른 검토자가 원문 조각 전문과 줄마다 대조했습니다. 아래 지적을 반영한 **전체 답**(같은 답 형식)을 다시 내 주세요.
- 지적이 없는 규칙 줄은 글·refs·quotes·순서를 **그대로** 둡니다. 불필요하게 다시 쓰지 않습니다.
- 줄 지적(뜻이 다름·과장·단정·빠짐·키 잘못)은 사유와 제안을 참고하되 제안을 그대로 베끼지 말고 위 원문 조각에 비춰 다시 확인해 고칩니다. 제안이 원문과 어긋나면 원문을 따릅니다. 고친 줄도 refs에 근거 조각 key를 모두 넣습니다.
- 줄 하나가 너무 길어지면 같은 절에서 줄을 나눠도 됩니다(나눈 줄마다 refs·인용).
- 문서 단위 지적(반영이 약한 중요 내용)은 해당 원문 key의 기준을 규칙 줄로 새로 넣거나 기존 줄에 보태 해결합니다. omitted에 있던 key에 기준이 있다면 omitted에서 빼고 규칙으로 옮깁니다. 사소한 배경은 옮기지 않아도 됩니다.
- 고친 판도 검산(key 실재·인용 글자 일치·모든 입력 key가 refs나 omitted에 있음·숫자는 refs 조각에 있는 것만)을 통과해야 합니다.
