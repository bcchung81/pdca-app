## 단계(테스트 먼저 → 구현 → 검증)

### A. 선택 장치(주요사업)
1. **틀 후보**(`lib/reports/story-hints.ts` 새 파일, 순수): 도식 후보(`diagramHints`)·글 신호·형제 초안이 쓴 틀 → 틀 후보 상위 3개(이유·여는 블록). 형제가 이미 쓴 틀은 뒤로.
   → 검증: `story-hints.test.ts`(협업 기관 3곳 → 다자협업형 1순위, 현장 말 → 현장 목소리형, 연도 4개 → 연혁형, 형제가 쓴 틀은 뒤로, 신호 없으면 빈 목록)
2. **「틀 고르기」 절**: `report-outline/request.md` `@storyHints`·`@storyHints.item`·`@storyHints.none`, `lib/ai/run.ts callReportOutline`이 요청에 붙임(사람이 틀을 골랐으면 안 붙임).
   → 검증: 프롬프트 절 대조 시험(`prompts.test.ts`), `storyHintsPrompt` 글 시험
3. **주 틀 + 보조 틀**: `Composition.subStory`(선택), 구성안 답 스키마 `story`는 8종(사람이 고정하면 그 하나), `subStory`는 빈 글 또는 8종(주 틀과 다른 것), 사람이 주 틀을 바꾸면 보조 틀은 지움. 화면 칩 「주 + 보조」, 형제 짜임 글에도 보조 틀.
   → 검증: `composition.test.ts`(정리·편집·옛 섞음 읽기), 스키마 시험
4. **여는 블록**: `report-draft/stories.md`에 여는 블록 규칙(틀의 첫 블록, 불릿으로 여는 것은 추진배경 말고 열 재료가 없을 때만), 틀 후보 글에 여는 블록.
   → 검증: `frameworks.test.ts` 틀 줄 대조(기존) + 여는 블록 절 존재
5. **골격 판정**: harness `diagram-pool.md`의 「판정표」를 `pickHeadings`로 발췌해 두 트랙 구성안 시스템 프롬프트 `{{skeleton}}`에 채움.
   → 검증: `rules.test.ts`(`pickHeadings` — 없는 제목이면 오류), 사본 대조 시험

### B. 경영관리 분리
6. **블록 사전 절 나누기**: `report-draft/blocks.md`를 `@blocks`(어휘)·`@figures`(그림 자리)·`@choose`(도식 고르기)로. 주요사업은 셋 다, 경영관리는 어휘 + 경영관리 전용 `report-draft-mg/blocks.md`(`@figures`·`@choose` — 구분표·추진성과 닫기·표 머리 줄 틀).
   → 검증: 경영관리 시스템 프롬프트(구성안·집필·블록 고치기)에 「같은 주요사업」·「반쪽 소항목」 문구 0건, 주요사업 프롬프트에는 그대로
7. **형제 짜임·도식 후보(경영관리)**: 같은 지표 다른 카드의 구성안·초안 절(평가내용·대주제·절 제목·틀)과 도식 후보를 요청에 넣고, 겹침 점검(`mgOverlapIssues`)을 구성안 점검에.
   → 검증: `mg-outline.test.ts`·`mg-draft.test.ts`(겹침 경고·요청 글)
8. **경영관리 틀 예시**: `report-draft-mg/stories.md`의 쪽 번호(모델이 못 보는 값)를 지표·위치 이름으로.
   → 검증: `frameworks-mg.test.ts`(줄에 「p숫자」 없음)

### C. 선별 다양화
9. **표 머리 줄 틀**: table-pool 파일4·파일2에서 고른 머리 줄을 블록 사전(경영관리 `@choose`, 주요사업 table 설명)에.
10. **새 블록 `strategy`·`pdca`**: `blocks.ts`(종류·정리·찬 정도), `frameworks.ts`(모양·칸 범위), `fit.ts`(칸 폭·높이·보통 모양), `section-html.ts`·`section-css.ts`(그림), `draft-text.ts`(직접 고치기 경로), 블록 사전·답 설명, 경영관리 틀 ①·⑤를 새 블록으로.
    → 검증: `blocks.test.ts`·`fit.test.ts`·`section.test.ts`·`draft-text.test.ts`·`frameworks(-mg).test.ts`
