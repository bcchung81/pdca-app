## 6. 검증

1. **시험**
   - 기존 출력 불변: 렌더·판면·HWPX 시험.
   - 새 틀·모양 시험: 견본 그림, 판면 어림, `matchName`, 경고 앞머리.
   - 판 해시 갱신: 주요사업 report-outline·report-draft·블록 고치기. 경영관리 판은 그대로여야 합니다.
2. **실호출(로컬 CLI — `AI_PROVIDER=cli`, API 크레딧 안 씀)**
   - 새 틀 신호가 있는 주요사업 카드 4~6장으로 구성안 → 집필을 돌립니다. 틀마다 1장 이상입니다.
   - **운영 DB에 쓰지 않는 경로**(스모크 스크립트 계열)로 만들어 localhost 정적 목록으로 보여 드립니다. 운영 저장은 사용자가 고른 것만 승인 뒤에 합니다(2026-10-29 「화면 확인 우선」).
   - 파싱 성공, 새 틀 선택, 경고 C1~C8 동작을 보고에 적습니다.
3. **화면**: ego lite로 짜임 고르기 갤러리(20종 견본), 새 모양 그림, 판면 칩을 봅니다. 화면을 바꾸면 두 트랙을 모두 캡처해 경영관리 불변을 확인합니다.
4. **한글**: 새 모양마다 1건씩 내려받기 → `validateHwpx` → 다시 읽기 왕복. 맥 한컴 뷰어 육안 확인은 P4가 끝난 뒤 한 번 합니다.
5. **못 하는 것**: `pnpm e2e`는 `DB_TARGET=production`이라 돌리지 않습니다(보고에 명시).
