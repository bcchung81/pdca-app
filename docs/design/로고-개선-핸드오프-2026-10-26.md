# Sherpa 로고 개선 핸드오프

- 작성일: 2026-10-26
- 대상: 디자인·프론트엔드·QA 및 후속 개발 담당자
- 상태: 로컬 소스 반영·검증 완료, 후속 확인 1~4 완료 뒤 운영 배포(2026-10-26, 아래 「배포 전 추가 확인」).
- 요청: 녹색 로고 색상 변경, 로고 품질 개선, ‘경영평가 Agent’ 부제 적용, 현황 분석과 개선안을 HTML로 작성.

기존 Summit Guide의 봉우리·상승 경로·별을 유지하면서 기본색을 앱의 남색과 통일했다. 제품명 **Sherpa**를 윗줄에, 역할을 설명하는 **경영평가 Agent**를 아랫줄에 배치했다. 후속 작업은 로그인 전 화면과 좁은 앱 헤더의 시각 검증, 인쇄 확인, 배포 전 빌드 확인부터 진행한다.

## 산출물

| 산출물 | 경로와 용도 |

HTML은 외부 스크립트·폰트·이미지 의존성 없이 단독으로 열 수 있다. 색상 라디오 선택은 문서 미리보기에만 적용되며 앱 설정을 저장하지 않는다. SVG 저장은 선택한 색상의 **심볼 단독** 벡터 파일을 내려받는다. 워드마크를 포함한 완성 로고 다운로드는 구현 범위에 포함하지 않았다.

## 변경 결정과 적용 규칙

| 항목 | 이전 | 반영값 |
| --- | --- | --- |
| 기본색 | 녹색 `#193D35` | 남색 `#1B1760`, 기존 UI의 `--navy`와 같은 값 |
| 길·별 강조색 | 연두 `#8DA969` | 블루 `#2563EB` |
| 워드마크 순서 | 경영평가 → Sherpa | Sherpa → 경영평가 Agent |
| 공용 SVG 별 두께 | `3` | `4` |
| 헤더 | 심볼 34px | 심볼 34px · 제품명 22px · 부제 12px |
| 로그인 | 심볼 48px | 심볼 48px · 제품명 28px · 부제 14px |
| 파비콘 | 녹색 바탕·흰 봉우리·연두 길과 별 | 남색 `#1B1760` 바탕·흰 봉우리·밝은 블루 `#93B4FF` 길과 별 |

- `Sherpa`와 `경영평가 Agent`는 HTML 텍스트로 표시한다. 앱의 공용 sans 글꼴을 사용하고 각각 줄바꿈하지 않는다.
- 부제는 헤더에서도 12px 이상을 유지한다. 좁은 화면에서 단순히 글자를 더 작게 줄이지 않는다.
- 흰 배경 대비는 기본색 약 15.69:1, 강조색 약 5.17:1이다. 이는 색상값으로 계산한 비율이며 모든 화면 상태의 접근성 검증을 대신하지 않는다.
- HTML의 슬레이트·버건디는 비교용 대안이다. 앱에는 남색·블루만 적용했다.
- 완료·경고·오류 등 업무 상태색과 업무 기능, 화면 구조는 이번 변경 범위 밖이다.

| 순서 | 다음 작업 | 수용 기준 |
| --- | --- | --- |
| 1 | 로그인·로그인 확인 화면 시각 검토 | 공용 로고의 48px 심볼·28px 이름·14px 부제가 잘림 없이 표시되고 폼과 겹치지 않음 |
| 2 | 앱 헤더의 좁은 화면·200% 확대 확인 | 로고·트랙 전환·과제 찾기·계정 영역의 겹침과 접근 불가 여부 확인. 문제가 있으면 헤더 배치 조정 범위를 별도로 정해 수정 |

재검증 명령은 저장소 루트에서 실행한다. Next.js 관련 코드를 더 수정하기 전 `AGENTS.md` 및 설치된 `node_modules/next/dist/docs/`의 해당 가이드를 확인한다.

```sh
pnpm exec tsc --noEmit
pnpm exec eslint components/shell/brand-mark.tsx app/login/auth-card.tsx 'app/(app)/layout.tsx' app/layout.tsx
node --test lib/design/style-guard.test.ts
git diff --check
pnpm build
```

로컬 확인은 `pnpm dev` 실행 후 `/dashboard`, `/login`, `/auth/confirm`, `/sherpa-brand-review.html`에서 진행한다. 활성 로그인 세션에서는 `/login`이 다른 화면으로 이동할 수 있으므로 로그인 전 화면은 별도 테스트 세션으로 확인한다.

## 검토 방법과 작업 트리 주의사항

Sequential Thinking MCP `@modelcontextprotocol/server-sequential-thinking@2.0.0`을 로컬 stdio로 임시 실행했다. `initialize` 이후 `sequentialthinking`을 3회 호출하여 현황, 개선 방향, 구현·검증 계획을 검토했으며 마지막 응답은 `nextThoughtNeeded=false`, `thoughtHistoryLength=3`이었다. 프로젝트 의존성과 MCP 연결 설정은 수정하지 않았다.

작업 시작 시 환경 예시·gitignore·AI provider와 오류 처리·기존 설계/운영 문서에 다른 변경이 있었고, 여러 미추적 문서·시안도 존재했다. 이를 이번 로고 변경으로 간주하거나 일괄 되돌리지 않는다. 핸드오프를 요청했다는 이유로 다른 에이전트 실행, 커밋, 배포는 수행하지 않았다.

이 문서와 [설계 문서 목록](./README.md)의 새 항목은 핸드오프 요청에 따라 추가했다. 이전 UI/UX 핸드오프는 별도 개선 제안이며 이번 로고 작업의 완료 범위에 포함하지 않는다.
