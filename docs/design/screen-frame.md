# 화면 틀(2026-10-01) — 한 줄 머리 · 통계 패널 · 현황 한 화면

사용자 승인(2026-10-01): 시안 **H1**(한 줄 머리+우측 세그먼트) · **S3**(진행 막대 통계) · **D2**(현황 시각 압축)을 모든 화면에 적용하고, 머리 아래·옆 서술형 부제는 전부 제거. 시안 캔버스: 설계 때 만든 「화면 틀·현황 시안 3종」(비공개).

## 왜 바꿨나
- 월간 점검은 표가 y≈467px에서 시작해 행이 5개만 보였음(앱 머리띠 48 + 화면 탭 53 + 제목줄 73 + 통계 카드 108 + 검색줄·상태 탭).
- 현황은 전체 높이가 약 2,770px(한 화면의 3.7배).
- 바꾼 뒤: 월간 점검 표 시작 y≈241(통계 패널·도구 줄 포함, 1309×727 창에서 9행), 현황은 같은 창에서 페이지 스크롤 0.
